# Dewdrop Garden Assets

Soft **game UI** icon set for 露珠小院 — matches Catppuccin Latte/Mocha chrome.

## Style contract (must keep)

- Soft clay / pastel mobile UI icons (not botanical illustration)
- **No thick black outlines**
- Catppuccin palette (flamingo, teal/green, lavender, yellow, mauve)
- Flower tiles keep soft solid UI background (inventory chip style)
- Logo may use transparency
- No text on assets
