# 露珠小院 · Dewdrop Courtyard

小清新休闲种田 Web UI 原型。界面采用 [Catppuccin](https://github.com/catppuccin/catppuccin) 配色：白天 **Latte**、黑夜 **Mocha**。

## 在线体验

GitHub Pages：https://xiaoqianran.github.io/Web003-dewdrop-garden/

（推送到 `main` 后由 Actions 自动部署）

## 玩法

播种 → 浇水 → 过夜成长 → 收获。  
底部「全浇」可对本地区所有未浇的植株一键浇水（每株仍消耗 1 体力；暖阳 / 竹径免费）。  
过夜时，**所有地区**的花圃都会一起生长。

右上角 🌙 可切换**黑夜模式**（Catppuccin Mocha），偏好会记在本机 `localStorage`。

进度会自动存到本机（`dewdrop-save-v1`）。再次打开可「继续照料」；也可在开场页「重新开始」清空进度。

### 出游地区

| 地区 | 解锁 | 特色 |
|------|------|------|
| 南窗花圃 | 第 1 天 | 9 格 · 胭脂芽 / 薄荷铃 |
| 雾丘浅坡 | 第 2 天 | 6 格 · 雾铃草 · 收获略多 |
| 浅滩河岸 | 第 3 天 | 6 格 · 水仙芽 · 过夜有概率多长一阶 |
| 竹径闲亭 | 第 5 天 | 6 格 · 竹影兰 / 薄荷铃 · 浇水免费 · 在此过夜次日体力 +2 |

点右上角「出游」打开地图。去外地会消耗少量体力；回家免费。

### 市贸广场

第 2 天起解锁（点「市贸」）：

| 档口 | 说明 |
|------|------|
| 买种 | 用金币购买全部种子 |
| 卖花 | 出售收获得到的花束（单价高于直接收获的金币） |
| 委托 | 每日 3 份花束订单，交付后酬劳高于零卖；过夜刷新 |
| 装点 | 第 3 天起：纸灯笼 / 风铃 / 石凳等，买后摆在南窗花圃边 |
| 小憩 | 薄荷露珠茶：◎15 换体力 +4 |

收获时除金币与种子外，会额外得到 1 束花，可拿到市贸卖出或交付委托。

### 图鉴与成就

点「图鉴」随时可看：

- **花草**：五种种子的嫩芽 / 花苞 / 盛开是否见过，以及累计收获次数
- **访客**：八位小院访客的结识与交情（初识 → 面熟 → 常客 → 老友）
- **成就**：轻量目标（首播、首获、出游、市贸、五日、攒金、五色花开、花谱写满、四时天色、竹径访客、委托、装点、访客等）

图鉴与成就进度会写入本机存档（`dewdrop-save-v1`，存档结构版本 v7，兼容读入 v1–v6）。

### 小院访客

第 4 天起，过夜后有概率迎来访客（橘猫、邻院姑娘、诗人、货郎等）。装点越多越容易来；对应装点会吸引特定客人。同一位客人多次来访会加深交情，礼物也更丰厚。横幅显示在南窗花圃。

### 每日天气

每晚「过夜」后刷新当天天气（按天数确定性生成，刷新页面不变）。花圃右上角显示当前天气与效果：

| 天气 | 效果 |
|------|------|
| ☀ 晴日 | 正常照料 |
| 🌧 细雨 | 未浇水的植株过夜也有机会生长 |
| 🌤 暖阳 | 浇水不消耗体力 |
| 🌫 薄雾 | 浇过水的植株过夜也可能不长 |
| 🌸 花信 | 收获金币与种子更丰 |
| 🍃 微风 | 出游体力消耗 −1 |

## 本地运行

用浏览器直接打开 `index.html` 即可，无需构建。

## 部署

仓库已配置 GitHub Actions → Pages：

- 工作流：`.github/workflows/deploy-pages.yml`
- 触发：`main` 分支 push，或手动 `workflow_dispatch`
- 产物：仅上传 `index.html` 到 Pages
